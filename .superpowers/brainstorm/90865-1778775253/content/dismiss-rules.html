🚫 悬浮框消失规则

严格定义：何时显示 / 何时消失

✅ 显示条件

显示

  • 用户在 Markdown 编辑器中用鼠标滑动选中任意文本

❌ 消失条件（仅限以下三种情况）

  • ① 点击空白区域 — 点击编辑器中未选中文本的区域
  • ② 按下 Escape 键 — 键盘 Esc 键
  • ③ 选择一个功能 — 点击任意样式/对齐/格式按钮并应用后自动消失

⚠️ 严格规则：以下情况 不 消失

  • ❌ 鼠标在悬浮框内部移动 → 不消失
  • ❌ 鼠标从编辑器选区内移动到悬浮框 → 不消失
  • ❌ 从悬浮框移回编辑器选区 → 不消失
  • ❌ 鼠标在悬浮框和选区之间来回移动 → 不消失
  • ❌ 点击下拉菜单但未选择选项 → 不消失
  • ❌ 编辑器失去焦点但鼠标仍在悬浮框上 → 不消失
  • ❌ 滚动页面 → 不消失（但需要重新定位）
  • ❌ 窗口大小变化 → 不消失（但需要重新定位）

实现要点

  • 必须使用 mousedown / click 事件精确判断点击目标
  • 不可使用 blur 事件监听（因为编辑器失焦不应导致消失）
  • 不可使用 mouseleave 事件监听（鼠标移出悬浮框不应消失）
  • 需要阻止悬浮框内部的点击事件冒泡，防止误判为"点击空白区域"
  • Escape 键监听需要处理事件冒泡，避免与其他插件冲突
  • 选择功能后，应用格式与消失之间应有一个平滑的过渡动画
